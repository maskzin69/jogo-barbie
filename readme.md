Jogo de Vestir
Um jogo mobile simples desenvolvido com React Native + Expo, no qual o jogador escolhe um personagem e pode personalizar sua aparência usando diferentes opções de cabelo, camisa, calça e calçado.

O jogador escolhe um personagem e pode trocar:

💇 Cabelo
👕 Camisa
👖 Calça
👟 Tênis

As roupas podem ser alteradas tocando na tela ou movimentando o celular usando o giroscópio.

Tecnologias:
React Native
Expo
JavaScript
Expo Sensors

Como executar:
npm install
npx expo start

Depois, abra o projeto pelo Expo Go no celular.
